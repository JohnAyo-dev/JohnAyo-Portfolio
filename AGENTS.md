# AGENTS.md

Personal portfolio site for JohnAyo Okeyode (Software Engineer, Product Builder & Founder, Meru Games / Meru Technologies). Visual style is a red-neon restyle inspired by Tobiloba Jagun's portfolio, used with the original creator's permission.

## Stack

- One file: `index.html` (HTML + a single `<style>` block + a single `<script>` at the end of `<body>`)
- Two files of code: `index.html` and `avatar-ascii.js` (loaded at the end of `<body>`). Vanilla JS only. No framework, no bundler, no npm, no dependencies
- Fonts (Google Fonts): Chakra Petch (display), Poppins (mono/eyebrows), Roboto (body). Do not swap them
- Assets: `avatar.jpg`, `JohnAyo.jpg`, `favicon.png`, `assets/projects/*.jpg` (tracker: `assets/projects/image.md`)

## Commands

None. Open `index.html` in a browser. Check desktop, mobile width, and `prefers-reduced-motion`.

## Design system

- Palette lives in `:root`. **`--gold` is now neon red `#FF1F3D` and `--cyan` is ember `#FF6B4A`** (names kept so old rules still work). Reuse variables, don't hard-code colours.
- Rounded corners (`--radius:18px`, cards 22px, pills for nav/buttons/chips), thin borders, uppercase spaced eyebrows.
- Allowed by owner request: neon glow on accents, liquid glass, tilt/spotlight/magnetic hover, small inline JS.
- Still banned: purple/blue palettes, bento grids, fake metrics/testimonials, extra fonts, Lucide, new dependencies.

## Feature map (where things live)

- Scroll progress bar: `#pbar` (fixed, scaleX driven by scroll)
- Liquid glass: SVG filter `#lg` at top of `<body>`; applied via `backdrop-filter` on nav, `.btn`, cards. Warp effect is Chromium-only, others get plain blur
- ASCII avatar: `avatar-ascii.js` draws the portrait as a canvas of `. - + =` characters that repel the cursor. It also removes any leftover `.robot`/`.hero-avatar`. The 64x64 grid is embedded in that file (canvas cannot read images on file://); regenerate it if `avatar.jpg` changes
- Solar system: `#solar` + `#pinfo` in `#stack`. Planets are **generated by JS from the real `.inv-slot` cards**, so edit the chips there, not the JS
- Experience stack: `#xps` (`.xp` cards) in `#education`. Click/Enter/Space toggles `.open`
- Hover mechanics: JS adds `data-tilt` to `.game-card,.inv-slot,.quest,.stat,.xp,.ach`; sets `--rx --ry --mx --my`; `.btn` gets a magnetic pull. Disabled on touch and reduced motion

## Content rules

The site is the source of truth. Don't invent users, revenue, dates, awards, clients or metrics. Don't inflate prototypes into products. Experience cards may only use facts already on the site. Cross-check `index.html` before adding claims.

## Gotchas

- `backdrop-filter:url(#lg)` only works in Chromium; keep the plain blur as the fallback.
- `.btn` uses `isolation:isolate` + `::after` for the glass warp. Don't remove it or the button text will distort.
- Five project images are still pending (see `assets/projects/image.md`). No image means no `<img>`.
- Keep `[data-tilt]` off elements that already use `transform` for layout.
- `handoff.md` holds change history. Append new updates there.

## Working rules

Small targeted edits. Don't rewrite the whole file for a small change. Preserve anchors, content and functionality. Optimise images (< 150 KB), use `loading="lazy"` below the fold.
- Nav is a floating liquid-glass island (fixed, pill). Hero is exactly one screen (`min-height:100svh`, no boxed frame)
- Background light strings: fixed `.strings` SVG (z-index:-1), CSS dash animation
- Games are a bento grid (card 1 = 2x2, card 4 = full width). Stack section: solar left, tiles right. Meru Vision is an HTML org chart (`.mv`) matching `assets/meru-vision.png`; edit the tiles there. Division colours intentionally follow the chart, not the red theme
- Lists over comma-separated project names

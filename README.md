# JohnAyo.dev

Personal portfolio of **JohnAyo Okeyode**: Software Engineer, Product Builder & Founder (Meru Games / Meru Technologies), Computer Science student at Covenant University.

## Highlights

- Neon red theme with liquid-glass surfaces
- Hero portrait built from `+ - . =` characters that scatter away from your cursor
- Scroll progress bar
- Interactive solar system built from the tech stack
- Click-to-expand experience stack
- Cards that tilt toward the mouse with a following spotlight, and magnetic buttons
- Honours `prefers-reduced-motion`; hover effects are off on touch devices

## Run it

No install. Open `index.html` in a browser (Chrome or Edge recommended for the full glass effect).

## Structure

```
index.html            the whole site (HTML + CSS + JS)
avatar.jpg            source portrait for the ASCII avatar
avatar-ascii.js       ASCII portrait that repels the cursor
JohnAyo.jpg           master image
favicon.png
assets/projects/      project screenshots (+ image.md checklist)
AGENTS.md  CLAUDE.md  rules and notes for AI/dev sessions
handoff.md            change history
```

## Deploy

Static hosting works as is (Vercel, Netlify, GitHub Pages). Upload the folder.
